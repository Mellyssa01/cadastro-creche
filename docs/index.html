Sobre o Projeto

Este sistema é uma aplicação em linha de comando (CLI) desenvolvida em Python para gerenciar o fluxo de registros de alunos em uma creche. Na presente etapa, a arquitetura foi integrada à API externa do ViaCEP para validação e preenchimento automático de endereços locais através do CEP.

Gerenciamento Local Persistência de dados estruturada in formato JSON dentro do diretório do projeto.
Integração via API Busca assíncrona de logradouros, bairros e localidades usando a API pública ViaCEP.
Análise Estática Formatação estrita e checagem de erros configurada através do Ruff (PEP 8).

Como Executar a Aplicação

  • 1. Clonar o repositório do GitHub

    Abra o terminal do seu ambiente local e realize o clone da branch de entrega:

    git clone https://github.com/Mellyssa01/cadastro-creche.git
cd cadastro-creche
  • 2. Rodar a aplicação CLI

    Execute o script principal utilizando o interpretador Python nativo:

    py src/main.py
  • 3. Executar o conjunto de testes

    Para rodar os testes unitários e de integração utilizando o ecossistema Pytest:

    py -m pytest
  • 4. Executar a checagem com o Ruff

    Para garantir que o padrão estético do código está de acordo com as especificações:

    py -m ruff check .
